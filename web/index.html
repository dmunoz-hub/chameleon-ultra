Magic UID · block 0

Build block 0 fills the data field above (UID · BCC · SAK 08 · ATQA 0004 · 8×00 — edit as needed), then Write UID sends it. Gen1a uses the backdoor unlock; Gen2 writes block 0 with the key above. A normal (non-magic) card will reject the UID write.

Key recovery · nested (WASM)
Known
Target

Needs one known sector key (use Find key first). Detects the tag's PRNG, collects nonces on-device, then cracks the target key in WebAssembly (the firmware's own nested/staticnested solver) and verifies it. Acquisition is probabilistic — re-run if it misses. Hardnested tags aren't supported here.

Key recovery · darkside (no known key)
Target

Recovers a first key with no key known, for weak-PRNG cards. Acquires repeatedly and intersects candidates in WASM until one verifies (can take several rounds). Fails with CANT_FIX_NT on cards with an unpredictable PRNG — those need hardnested (iOS app).

LF · EM410x → T5577

Read the source EM410x tag → swap in a blank T5577 → Write + Verify re-reads the card and compares.

Slots & emulation

Load slots to see the 8 emulation slots; toggle HF/LF per slot and pick the active one. Emulate scanned/read loads the last HF UID or EM410x ID into the active slot and switches the Chameleon to tag mode so it acts as that card. Save to flash to keep it across reboots.
